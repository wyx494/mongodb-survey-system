# 测试用例与结果

测试分两层：

1. **自动化测试**：`npm test`，共 37 个用例（14 个单元测试 + 23 个 API 集成测试），跑在独立的测试库上，结束后自动删库。
2. **浏览器端检查**：用 Playwright 打开真实页面，验证编辑器保存、逐题跳转、完整提交和统计展示。

最后一次执行：2026-10-22，全部通过。

## 六、没有覆盖到的部分

- 没有做并发压力测试（需求只要求“支持多人同时填写”，代码层面每次提交是独立插入，不会互相阻塞）。
- 没有做移动端适配的自动化检查。
- 没有做 XSS/CSRF 的自动化安全扫描；EJS 默认转义、Cookie 设了 SameSite=Lax，但没有 CSRF token。
